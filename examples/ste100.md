## B STE 句子剖析 {span=4 meta="标注示例"}
```annot
# 原文，非 STE | 未批准词标红
It is [imperative]{!} that the operator [ensures]{!} the hydraulic reservoir is [replenished]{!} [prior to]{!} [commencing]{!} operation.
# 1 程序性句子 | 13 词，上限 20
[Make sure]{批准动词，命令形式} that [the hydraulic reservoir]{技术名称，最多 3 词} is [full]{不用 "replenished"} [before]{不用 "prior to"} [you]{主动语态} [start]{不用 "commencing"} the operation.
# 2 安全说明
[WARNING:]{!WARNING = 受伤风险} [Do not touch the brake unit until it is cool.]{首先：清晰、简单的命令} [Hot parts can cause injury.]{然后：风险}
# 3 描述性句子 | 12 词，上限 25
The pump [supplies]{一般现在时} fuel to the engine when the switch is on.
> 每段最多 6 句。每段一个主题。
```

## C 动词形式 {span=2 meta="第 3 节"}
| 形式 | 示例 | 状态 |
|---|---|---|
| 命令式（祈使） | `Close the valve.` | ok 已批准 |
| 一般现在时 | `The valve closes.` | ok 已批准 |
| 一般过去时 | `The valve closed.` | ok 已批准 |
| 一般将来时 | `The valve will close.` | ok 已批准 |
| 不定式 | `Turn the knob to close it.` | ok 已批准 |
| 过去分词（作形容词） | `The closed valve` | ok 已批准 |
| 进行时（-ing） | `The valve is closing.` | no 未批准 |
| 完成时 | `The valve has closed.` | no 未批准 |
| 被动语态，用于程序 | `The valve must be closed.` | no 未批准 |

仅在技术名称中使用 -ing 形式，例如 "landing gear"。

## D 词典条目 {span=4 rows=2 meta="第 2 部分格式"}
| 词（词性） | 状态 | 含义或替代词 | 批准示例 | 未批准 |
|---|---|---|---|---|
| `CLOSE (v)` | ok 已批准 | 合拢；停止流动 | CLOSE the valve. | – |
| `close (adj)` | no 未批准 | NEAR | Put the tool NEAR the panel. | ~~Put the tool close to the panel.~~ |
| `commence (v)` | no 未批准 | START | START the pump. | ~~Commence pumping.~~ |
| `ensure (v)` | no 未批准 | MAKE SURE | MAKE SURE THAT the switch is off. | ~~Ensure the switch is off.~~ |
| `prior to (prep)` | no 未批准 | BEFORE | BEFORE you start the engine, | ~~Prior to starting the engine,~~ |
| `replenish (v)` | no 未批准 | FILL | FILL the reservoir. | ~~Replenish the reservoir.~~ |
| `utilize (v)` | no 未批准 | USE | USE a torque wrench. | ~~Utilize a torque wrench.~~ |
| `approximately (adv)` | no 未批准 | ABOUT | Wait for ABOUT 10 minutes. | ~~Wait approximately 10 minutes.~~ |

批准词为大写。未批准词为小写。批准词仅保留其列出的含义和词性。

## E 写作规则限制 {span=2 rows=2 meta="最大值"}
```limits
程序性句子 | 最多 20 | 词
描述性句子 | 最多 25 | 词
描述性段落 | 最多 6 | 句
名词簇 | 最多 3 | 词
每句中的指令 | 最多 1 | | 同时动作除外
```
- 同一事物始终使用同一个词。
- 不要省略 "the"、"a" 和 "this" 等词。
- 在程序中使用主动语态。
- 对复杂文本使用垂直列表。
- 每段只写一个主题。
